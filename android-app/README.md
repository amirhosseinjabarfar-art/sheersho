# بیتو (BEYTO) — Android app

نسخهٔ اندروید قابل توسعه برای سایت بیتو؛ نام بسته: `ir.amirhossein.myapp`، نسخهٔ نمایشی: `2.0`.

## ویژگی‌ها
- اپ اندروید بومی با WebView تمام‌صفحه و حالت عمودی
- بارگذاری سایت فعلی: https://amirhosseinjabarfar-art.github.io/sheersho/
- JavaScript، DOM storage و کوکی‌ها فعال‌اند تا ورود و نشست‌های وب تا حد سازگاری WebView کار کنند.
- اتصال به بک‌اند سایت دست‌کاری نمی‌شود؛ امتیازها و حساب‌ها همچنان از خود سایت و Supabase مدیریت می‌شوند.
- آیکون اختصاصی، دکمهٔ بازگشت اندروید، صفحهٔ بارگذاری و مدیریت لینک‌های وب
- گردش‌کار GitHub Actions برای ساخت APK آزمایشی به‌صورت خودکار

## ساخت APK در ویندوز
1. پوشهٔ `android-app` را از مخزن دریافت کنید یا مخزن را با Git کلون کنید.
2. Android Studio و Android SDK را نصب کنید.
3. پروژه را با باز کردن همین پوشهٔ `android-app` وارد Android Studio کنید.
4. اجازه دهید Gradle همگام‌سازی شود، سپس از منوی Build گزینهٔ Build APK(s) را انتخاب کنید.

برای ساخت از خط فرمان، از داخل `android-app` اجرا کنید:
```bash
gradle assembleDebug
```
خروجی: `app/build/outputs/apk/debug/app-debug.apk`.

## ساخت APK از GitHub Actions
Workflow موجود در `.github/workflows/build-android.yml` با هر تغییری در فایل‌های پروژهٔ اندروید یا با اجرای دستی، پروژه را می‌سازد و APK را به‌عنوان Artifact با نام `beyto-debug-apk` ذخیره می‌کند. در GitHub به زبانهٔ Actions بروید، اجرای موفق را باز کنید و Artifact را دریافت کنید.

## نکته‌های مهم
- این پروژه سورس اپ است؛ APK امضاشده برای انتشار عمومی جداگانه باید با کلید انتشار خودتان ساخته شود. APK دیباگ برای نصب و آزمایش است.
- اولین اجرا و همهٔ امکانات آنلاین به اینترنت نیاز دارند.
- چون برنامه همان سایت فعلی را نمایش می‌دهد، رفع باگ‌های سایت و Supabase همچنان باید در خود سایت/بک‌اند انجام شود. این بسته هیچ جدول یا امتیازی را پاک یا تغییر نمی‌دهد.
- برای حفظ امنیت، رمز عبور یا کلیدهای خصوصی Supabase را داخل اپ قرار ندهید.
